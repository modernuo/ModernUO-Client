Real macOS/Linux runs need a Mac or Linux machine. It lands right after the pack-text merge (same line in `Main.cs`).

## Decisions you made tonight (recorded in README "Decisions so far" and in memory)

- **One source of truth per pack file** (2026-10-31): `hues.bin` (the RGBA8 hue LUT) is removed; the client builds it at startup from `hues_raw.bin`. The reason isn't the 384 KB saved: tools will be built around the pack files, and two files that must stay in sync are error-prone. Data that can be cheaply rebuilt from another pack file is rebuilt at load, not stored. *Agent started 2026-10-31.*
- **Data pipeline: MUL/UOP → source format → shipped pack** (2026-10-31): MUL/UOP are import-only (imported once; nothing goes back to them). The source format is the definitive, edited data: one file or folder per thing an admin edits, images in UO's own layouts uncompressed (16-bit B5G5R5A1; Indexed8 plus palette for animations). The shipped pack is a build output: optimised, never hand-edited, built incrementally with stable packing so patches stay small. ModernUO, CentrED# and UOFiddler will be updated to it. Lower mip levels in art and texture pages stay stored (derived, but expensive to rebuild). Spec agent and the per-graphic-records measurement PoC started 2026-10-31.
- **Art and animations ship as pre-packed pages, with stable packing** (2026-10-31): per-graphic records were built and measured (records-eval.md). Same pixels, and the same frame times pinned. Records cost about +0.5 s per launch, +50–80 MiB of commit per client and 2.3× the art-page load latency, for 3–20 % less disk. Patch size is handled by stable packing + CDC. `poc/records-eval` is kept as a reference and not merged.
- **A pack version per format change** (2026-10-31): `classic-1.1` is published when the tiledata change merges (its client can't read 1.0's tiledata), not held back for music and sounds. Each later format change gets its own version (1.2, 1.3, ...). Versions are immutable folders, mostly hard links, so each costs only its changed files. `CURRENT` flips once queued jobs with older binaries have run, and an old version is deleted once nothing uses it.
- **Stable packing + CDC patching** (2026-10-31): the build step packs stably. Unchanged sprites keep their page and position; groups (an anim body, an art id range) move together when they outgrow their space; pages keep some slack; a deliberate `--repack` defragments. Patches use content-defined chunking, so large files are fine as long as compression stays per chunk or per record. GPU performance must not drop: churned-pack vs fresh-pack measurement is part of the work. *Queued after the tiledata change merges.* Data-format answers Q1–Q10 are in data-formats.md §10 (Q3 maps pending the CentrED# survey, Q10 audio pending the audio survey).
- **One tiledata file; ClassicUO's hard-coded rules become data** (2026-10-31): `tiledata.bin` (the renderer's compact copy) goes; the renderer builds its compact arrays at load from the full tiledata file. ClassicUO's hard-coded "never draw" rules (tile-id lists, the `nodraw` name prefix, the easel version rule, land 0–2, `NoDiagonal`) are applied once, by the converter, and stored as per-tile flags in that file. The client keeps no copy of the rules: the file decides, so shard admins can hide or show tiles without a code change. *Queued after the hues change merges.*
- **Several clients at once is a requirement** (2026-10-30): players run 3–4 clients, and problems have appeared with 3 or more. No instance may corrupt or block another (profiles, settings, logs, packs), and per-instance memory must suit 4 instances. The static chunk pool you asked about was upstream (in `Chunk.cs` since 2023) and can't affect separate instances: each client is its own process. Recorded in README "Decisions so far".
- **Legacy is a developer-only comparison mode** (2026-10-24). There's no automatic fallback to it. It's kept mainly to catch Gpu bugs, and it will be deleted once parity uses saved reference shots. *Implemented in a6110f967.*
- **SDL fork:** agents may push fixes to github.com/modernuo/SDL without asking first. The client may build SDL3.dll from the fork. Upstream (libsdl-org) contributions stay forbidden. *In progress (page-fault agent).*
- **Keep Legacy for now** (2026-10-25, after your FPS test): it may be the low-end-hardware path. Delete it only once the supported hardware range is decided. The Legacy regression is therefore being fixed, not just explained.
